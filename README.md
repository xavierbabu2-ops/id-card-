### 📲 APK ஃபைல் டவுன்லோட் செய்வது எப்படி? (How to Download APK)

#### வழி 1: GitHub மூலமாக APK டவுன்லோட் செய்தல் (GitHub Actions & Releases)
1. இந்த ப்ராஜெக்ட்டை உங்கள் GitHub கணக்கில் **Push** செய்தவுடன், தானாகவே **GitHub Actions** இயங்கி APK கோப்பை உருவாக்கிவிடும்.
2. உங்கள் GitHub Repository-ல் மேலே உள்ள **Actions** டேப் (Tab) செல்லவும்.
3. சமீபத்திய **Build Android APK** கிளிக் செய்து, **Artifacts** பகுதியில் உள்ள **`TN_Painters_ID_Card_APK`** கோப்பை உடனே டவுன்லோட் செய்து மொபைலில் இன்ஸ்டால் செய்யலாம்!
4. அல்லது **Releases** பக்கத்தில் புதிய வெர்ஷன் டேக் (Tag) உருவாக்கும் போது தானாகவே APK ஃபைல் ரிலீஸ் பக்கத்தில் டவுன்லோட் செய்யக் கிடைக்கும்.

#### வழி 2: Google AI Studio மூலமாக நேரடி APK உருவாக்கம்
1. AI Studio மேல் வலது மூலையில் உள்ள **Settings / Export** மெனுவை கிளிக் செய்யவும்.
2. **Export as ZIP** அல்லது **Push to GitHub** அல்லது **Generate APK / AAB** என்பதைத் தேர்ந்தெடுத்து நேரடியாகப் பெறலாம்.
